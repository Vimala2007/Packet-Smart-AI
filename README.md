# PocketSmart AI

A personal budget and spending dashboard that runs directly in your browser. Transactions and budget preferences are saved locally in your browser.

## Requirements

- Node.js 20.19+ and npm

## Get started

```sh
npm install
npm run dev
```

Vite prints the local development URL when the server starts.

## Production build

```sh
npm run build
npm run preview
```

You can also open `index.html` directly in a browser without installing dependencies.
